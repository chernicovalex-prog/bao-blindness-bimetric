# BAO Blindness to Bimetric Gravity

Воспроизводимый материал к статье о «BAO-слепоте» биметрической гравитации
(формализм Хассана—Розена / Хёгоса—Мёртселла) в сравнении с ΛCDM
по данным BAO (DESI DR2), сверхновых (Pantheon+SH0ES) и ранневселенского
интеграла (CMB-прокси). Базовая точка: θ = 6.1°, m_FP = 25 H₀, α = 0, β = 3.

## Методология: оркестр независимых ИИ

Эта работа выполнена независимым исследователем при организации вычислений
и верификации несколькими ИИ (Kimi/«Алиса» — администрирование и журнал,
DeepSeek, Qwen, GLM — слепые независимые задачи). Рабочий журнал и дневник
— не украшение, а **лабораторные записи**: они документируют, как именно
была организована много-ИИ проверка научной работы, какие ошибки ловились
и какие правила из этого родились.

Итог программы верификации: CMB ×3 независимых кода, BAO ×2 кода
(2 схемы ковариаций), SNe ✓✓, теория ✓×2. Ни одно каноническое число
не изменилось.

## Правила, которые помогли в организации эффективной работы множества ИИ

Полный свод правил — в рабочем журнале (домены A–E). Здесь — по одному
из каждого домена, те, что больше всего нам пригодились:

**A. Канонические числа. Обновление числа = новая ревизия (A3).**
Каждое каноническое число хранится с маркером достоверности; любое его
изменение фиксируется новой ревизией журнала. Число без маркера —
недействительно.

**B. Внешние проверки. Домашнее число снимается только извне (B4).**
Число, полученное «дома», помечается маркером 🏠. Он снимается, когда:
(а) код другого ИИ воспроизвёл число, (б) данные из независимой работы
совпали, (в) сверка другим ИИ подтвердила.

**C. Ведение журнала. Одна запись = одна задача, новые сверху (C1).**
Каждое действие — отдельная запись лога со статусом и маркером.
Ничего не удаляется: старые записи архивируются, а не стираются —
история не раз спасала проект при потере контекста ИИ.

**D. Формат документов. Источник истины — Markdown (D1).**
Все документы живут в .md/.txt: это читается ИИ без потерь, diff-ится
и не требует пересборки. Правки — точечные, каждая ревизия —
осмысленный дифф.

**E. Доказательность. Отчёт ≠ прогон (E1).**
Присланный отчёт ИИ не является доказательством; доказательство —
код, дословно сохранённый в файл с sha256 до запуска, плюс реальный
прогон с логом.

## Как пользоваться журналом и дневником

Если вы хотите повторить подобную организацию работы в своём исследовании:

1. Назначьте один ИИ «администратором»: он ведёт журнал, хранит канон,
   выдаёт слепые задания и фиксирует все входы/выходы с хешами.
2. Внешним ИИ давайте **самодостаточные** задания: полные уравнения,
   явные конвенции (например, замыкание Ω_Λ = 1 − Ω_m − Ω_r), ноль
   целевых чисел.
3. Несовпадения не «чините молча» — ищите конвенцию. Наша самая полезная
   находка родилась из расхождения 0.1763 vs 0.1948: дело было не в
   ошибке, а в другом определении ΛCDM-контроля.
4. Ведите журнал так, будто завтра ИИ потеряет весь контекст. Потому что
   однажды он его потеряет.
