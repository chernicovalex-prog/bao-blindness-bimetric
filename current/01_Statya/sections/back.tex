\section*{Data and code availability}
The DESI~DR2 BAO data are publicly available from the DESI data-release pages; the Pantheon+ data from the \texttt{PantheonPlusSH0ES} \texttt{DataRelease} repository; the compressed-CMB vector and covariance are published by \citet{Bansal2025}. The code base \code{bimetric\_r28} reproduces every number and figure reported here from those public inputs, including the anchor profile (\code{src/anchor\_scan.py}), the scalar-sector scans (\code{src/scalar\_mfp\_scan.py}), the self-similar reduction (\code{src/selfsim.py}), the supplementary numbers (\code{src/extra\_numbers.py}) and the figures (\code{src/make\_figures.py}). It is distributed with this submission as ancillary files. The current staged pipeline is recorded in \code{run\_all.sh} with fixed grids and seeds. The reported evidence was obtained by durable per-stage execution with checkpoints and individual return-code logs; no single uninterrupted monolithic run is claimed.
